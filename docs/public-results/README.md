## Evidence Labels

- **PASS** means the stated acceptance criterion passed inside the disclosed
  virtual test; it is not a claim of real-world durability.
- **FAIL** identifies a redesign item found by a conservative conceptual screen.
- **INCONCLUSIVE** means missing inputs or model fidelity prevent a defensible
  decision.
- **PRELIMINARY** means a simulation result has not been correlated against
  physical test data.

See [Methodology and limitations](methodology_and_limitations.md) before using
these values in technical or investment decisions.
